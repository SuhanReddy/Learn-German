# 🇩🇪 Learn German

A simple and interactive website for practicing German vocabulary.

You can play different types of exercises, such as **German → English**, **English → German**, **4-option quizzes**, **article practice (`der · die · das`)**, and **Mixed Practice**.

The project is built with simple **HTML, CSS, and JavaScript**, so it is easy to understand and customize.

### 🚀 Getting Started

No installation is required. Just open `index.html` in your browser and start learning.

### 📚 Add More Words

The vocabulary is stored in `script.js` inside the `words` array.

You can easily add more words whenever you want:

```javascript
["Haus", "house", "Basics", "das"]
```

There is no fixed vocabulary limit — you can keep expanding the word list with **200, 500, 1000+ words** and use them in your practice.
